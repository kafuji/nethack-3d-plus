# ドット絵由来の段差の修正

## トラバサミとホイッスルの再制作

前回の修正版も形が不自然という指摘を受け、2原画を実物の構造から新しく描き起こし、共有先を含む3キーへ差し替えた。トラバサミは両側の半円形の顎が中央の踏み板を囲む、開いた状態の道具として描いた。ホイッスルは円筒形の胴、短い吹き口、上面の発音口、丸い側板を持つ形に描いた。記号としての大きな歯と笛の輪郭は維持している。

生成器へ渡した画像は金属表現の画風見本のみ。前回の不自然な形やPixelHackは形の参照に使用していない。元絵は仕上げ時の配置・サイズ合わせに使用し、縦横比は保持する。

[直前の版との比較](mechanical-rebuilt/compare-01.png) / [48pxの暗色・明色背景での確認](mechanical-rebuilt/final-01.png) / [実際の生成プロンプトと参照画像](mechanical-remake.json)。以前の13原画の生成記録では、この2件を `superseded` として区別した。

**13原画すべて修正済み（共有先を含む16キー）。** 見やすさのための記号性を維持し、形状と模様の画素由来の段差を修正した。内蔵生成器で、保存した高解像度の修正前画像を編集対象に使用。PixelHackの画素形状を再び写さないよう、今回の編集入力には元のドット絵を渡していない。配置と大きさの仕上げには既存の `fit.matchRef` を使用した。

- [修正後13点：大きい表示と48pxの暗色・明色背景](repaired/final-01.png)
- [修正前後の比較1](repaired/compare-01.png) / [比較2](repaired/compare-02.png) / [比較3](repaired/compare-03.png)（各組の左が修正前、右が修正後。両方256px）
- [実際の生成プロンプト・参照画像・仕上げコマンド](repair-generation.json)

三角形の護符、燭台の7本の枝、罠の大きな歯、布の十字、Tシャツの胸の図柄、包装のK・Cは保持。結晶の兜のカット面や鍵の歯も意図した形状として残した。

全483キーの検査は、256×256・透過、旧画像0、欠落0、エラー0、共有24組一致。[検査結果](../validation.json)。ゲーム内確認はユーザーが行う。

## 今回の抽出基準

- 大きな水平・垂直の段差が、元絵の丸みや斜辺の画素と対応している。
- 画素のまとまりが、そのまま厚い部品や矩形の模様になっている。
- 六角形・立方体の護符、宝石や結晶のカット面、刃物の歯、格子柄・市松模様は、それ自体を理由に候補にしない。
- `mottled__sleep`、`stained__finger_of_death`、`dusty__magic_mapping`、`dull__protection` も個別比較した。現行の斑点は不規則な曲線に描き直されており、明確な階段状の模様ではないため優先候補から外した。汚れや質感としての良し悪しは別の評価になる。
- 武器71点と最後に追加した杖13点には、今回の基準で優先候補にするほど明確な画素の段差は見つからなかった。
