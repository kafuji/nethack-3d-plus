メニューの操作キー：

           全体    現在の
                   ページ
  選択       .      ,
  反転       @      ~
  解除       -      \

  移動       >      次のページ
             <      前のページ
             ^      最初のページ
             |      最後のページ

  検索       :      文字列を入力し、一致する項目をすべて反転する

  その他   Return   現在の選択を確定してメニューを閉じる
           Enter    Return と同じ
           Space    最後のページでなければ1ページ進む。
                    最後のページでは Return と同じ
           Escape   何も選ばずにメニューを取り消す
