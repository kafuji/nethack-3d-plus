           犬で始まる職業には、名前があらかじめ決まっているものもある
           （たとえば侍の "Hachi"）。dogname を指定すると上書きされる。
gender     開始時の性別（male、female、random）。                  [random]
           最初の1文字だけでも指定できる。古い真偽値オプション "male" と
           "female" でも指定できるが、"gender" オプションが優先される。
horsename  最初のペットが子馬のときの名前                            [none]
menu_*     メニューコマンドの1文字のキーを指定する。
           次はコマンドと既定のキーと、対応するウィンドウポートの一覧：
           （t は tty、c は curses、w は Windows GUI、x は X11、q は Qt）
           menu_first_page    メニューの最初のページへ              [^](tcwxq)
           menu_last_page     メニューの最後のページへ              [|](tcwxq)
           menu_next_page     メニューの次のページへ                [>](tcwxq)
           menu_previous_page メニューの前のページへ                [<](tcwxq)
           menu_shift_left    表示を左へ動かす（perm_invent のみ）  [{](cx)
           menu_shift_right   表示を右へ動かす（perm_invent のみ）  [}](cx)
           menu_select_all    メニューのすべての項目を選ぶ          [.](tcwxq)
           menu_select_page   このページのすべての項目を選ぶ        [,](tcwq)
           menu_deselect_all  メニューのすべての選択を解除する      [-](tcwxq)
           menu_deselect_page このページのすべての選択を解除する    [\](tcwq)
           menu_invert_all    メニューのすべての選択を反転する      [@](tcwxq)
           menu_invert_page   このページのすべての選択を反転する    [~](tcwq)
           menu_search        文字列を入力し、一致する項目の        [:](tcwxq)
                              選択を反転する
msghistory 保存する最上行のメッセージの数                              [20]
name       キャラクターの名前      [マルチユーザーのシステムではユーザー名が
           既定。シングルユーザーのシステムや、"games" のような汎用のユーザー
           名では「お名前は？」と尋ねる]
           MS Windows はユーザー名に対応しているが、シングルユーザーとして
           扱う。コマンドラインで名前を指定すると（システムやアクセス方法に
           よるが、通常は 'nethack -u myname'）、オプションの 'name' より
           優先される。
pettype    希望するペットの種類（cat、dog、horse、random、none）。 [random]
           職業が複数の種類を許す場合（または最初のペットを避けたい場合）に
           使う。ほとんどの職業は犬か猫で、馬は選べない。種類が決まっている
           職業では、'none' の指定を除き pettype は無視される。
playmode   通常プレイ、スコアなしの探検モード、デバッグモード      [normal]
race       開始時の種族（例：race:Human、race:Elf）。              [random]
           ほとんどの職業では選べる種族が限られる。
role       開始時の職業（例：role:Barbarian、role:Valk）。         [random]
           最初の数文字だけでも指定できるが、最初に一致した職業が選ばれる
           ため、職業名はなるべく長く書くことを勧める。"name" オプションの
           末尾に付けても指定できる（例：name:Vic-V）が、"role" オプションが
           優先される。
windowtype 使用するウィンドウシステム    [OS とコンパイル時の設定による]
           複数の選択肢があるときに指定する。1種類にしか対応しないプログラムも
           あり、その場合は指定は不要。対応するウィンドウの種類の一覧は、
           プログラムの実行中に #version コマンドで、または外部からビルド時に
           生成される 'options' というテキストファイルで確認できる。

オプションの一覧の例：
!autopickup,!tombstone,name:Gandalf,scores:own/3 top/2 around
female,nonews,dogname:Rover,rest_on_space,!verbose,menustyle:traditional
