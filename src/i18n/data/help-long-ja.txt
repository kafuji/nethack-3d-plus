        NetHack へようこそ！                （バージョン 3.6 の説明）

        NetHack は「ダンジョンズ＆ドラゴンズ」に似たゲームです。あなた（冒険者）はイェンダーの魔除けを求めてダンジョンの奥深くへ下りていきます。魔除けは20階より下のどこかに隠されていると言われています。冒険はペットと一緒に始まります。ペットはさまざまな形であなたを助けてくれ、いろいろなことを覚えさせることもできます。道中では、役に立つ（または立たない）アイテムが見つかります。魔法の力を持つものも少なくありません。さまざまなモンスターにも出会います。モンスターのいるマスへ移動しようとすると攻撃できます（ただし、放っておくほうがはるかに賢明な場合もよくあります）。

        現在地を文章で説明する多くのアドベンチャーゲームとは違い、NetHack はいる階のダンジョンを図として見せてくれます。

        NetHack では次の記号を使います：

        - と |   部屋の壁。開いた扉や墓の場合もある。
        .        部屋の床または戸口。
        #        通路、鉄格子、木、流し台（ダンジョンに流し台がある場合）、
                 または跳ね橋。
        >        下り階段：次の階へ行ける。
        <        上り階段：前の階へ行ける。
        @        あなた（普通は）、またはほかの人間。
        )        何らかの武器。
        [        鎧または防具。
        %        食べられるもの（健康に良いとは限らない）。
        /        杖。
        =        指輪。
        ?        巻物。
        !        ポーション。
        (        その他の役に立つ物（つるはし、鍵、ランプなど）。
        $        金貨の山。
        *        宝石または石（高価かもしれないし、無価値かもしれない）。
        +        閉じた扉、または覚えられる呪文が載った魔法書。
        ^        罠（見つけた後）。
        "        護符、またはクモの巣。
        0        鉄球。
        _        祭壇、または鉄の鎖。
        {        泉。
        }        水たまり、堀、または溶岩だまり。
        \        豪華な玉座。
        `        大岩または石像。
        A～Z、a～z、ほか数種類：  モンスター。
        I        見えないモンスターが最後にいた場所。

                 記号が何を表すかは、'/' を入力し、案内に従って
                 カーソルをその記号へ動かすと分かります。たとえば
                 'd' は犬かもしれません。


y k u   7 8 9   移動コマンド：
 \|/     \|/            yuhjklbn: 指定した方向へ1歩進む
h-.-l   4-.-6           YUHJKLBN: 壁にぶつかるか何かに出会うまで
 /|\     /|\                      指定した方向へ進み続ける
b j n   1 2 3           g<方向>:  何か興味深いものが見えるまで
      テンキー                    指定した方向へ走る
                        G<方向>,  同上。ただし分岐する通路を
 <  上る                ^<方向>:  興味深いものとみなさない
                                  （ここでの ^ は Control キーのこと）
 >  下りる              m<方向>:  物を拾わずに移動する
                        F<方向>:  モンスターの気配がなくても攻撃する
                number_pad オプションを設定すると、数字キーで移動する。
                環境によっては Shift+数字（テンキー）、Meta+数字、
                Alt+数字で YUHJKLBN コマンドを実行できる。
                number_pad が有効なとき、Control+<方向> が使えるかどうかは
                環境によって異なる。
                数字の '5' は 'G' 接頭辞として働く。ただし number_pad が 2 の
                ときは 'g' として働く。
                number_pad が 3 のときは 1,2,3 と 7,8,9 の役割が逆になる。
                4 のときは 3 と 2 を組み合わせた動作になる。
                number_pad が -1 のときは英字の移動コマンドを使うが、
                'y' と 'z' が入れ替わる。

コマンド：
        NetHack には次のコマンドがあります：
        ?       ヘルプメニュー。
        /       記号が何を表すかを教える。場所を指定するか、記号を入力する。
                autodescribe オプションを有効にすると、カーソルを動かした
                先の記号の情報を表示する。
        &       コマンドの働きを教える。
        <       階段を上る（階段の上に立っているとき）。
        >       階段を下りる（階段の上に立っているとき）。
        .       休む。1ターン何もしない。
        _       最短経路でマップ上の地点へ移動する。
        a       道具（つるはし、鍵、ランプなど）を使う。
        A       すべての防具を脱ぐ。
        ^A      直前のコマンドをもう一度実行する。
        c       扉を閉める。
        C       モンスター、個別のアイテム、アイテムの種類に名前を付ける。
        d       物を置く。d7a：アイテム a を7個置く。
        D       複数の物を置く。このコマンドには2つの方式があります。
                1つ目の方式：
                "D" を押すと持ち物の一覧が表示され、置く物を選べます。
                アイテムの横の "+" は置くこと、"-" は置かないことを表します。
                説明の横の文字を入力すると選択を切り替えられます。
                "+" ですべて選択し、"=" ですべての選択を解除します。
                <スペースキー> で一覧の次のページへ進みます。
                2つ目の方式：
                "D" を押すと「どの種類の物を置きますか？ [!%= au]」と
                尋ねられます。アイテムの記号を0個以上入力し、必要なら
                続けて 'a' や 'u' を入力します。
                Da - 確認なしですべての物を置く。
                Du - 未払いの物だけを置く（店の中で）。
                D%u - 未払いの食べ物だけを置く。
        ^D      蹴る（普通は扉を）。
        e       食べる。
        E       床に文字を刻む。
                E- - 指でほこりに書く。
        f       矢筒の弾を発射する。
        F       方向を続けて入力し、モンスターを攻撃する（気配がなくても）。
        i       持ち物を表示する。
        I       持ち物の一部を表示する。たとえば
                I* - 持っている宝石を一覧表示する。
                Iu - 未払いの物を一覧表示する。
                Ix - 使ってしまった、勘定に載っている物を一覧表示する。
                I$ - 所持金を数える。
        o       扉を開ける。
        O       現在のオプションを確認し、必要なら変更する。
                オプションの設定がメニューで表示され、ほとんどは項目を
                選ぶだけで変更できます。オプションは 'O' コマンドより、
                ゲームの前に環境変数 NETHACKOPTIONS や設定ファイル
                （defaults.nh、NetHack Defaults、nethack.cnf、
                ~/.nethackrc など）で設定するのが普通です。
        p       買い物の代金を支払う。
        P       装身具（指輪、護符など）を身に着ける。
        ^P      直前のメッセージを再表示する（^P を続けるとさらに前へ）。
                動作は msg_window オプションで変えられます。
        q       何か（ポーション、水など）を飲む。
        Q       矢筒に入れる弾を選ぶ。
        #quit   現在のゲームを保存せずに終了する。
        r       巻物または魔法書を読む。
        R       装身具（指輪、護符など）を外す。
        ^R      画面を再描画する。
        s       周囲の隠し扉と罠を探す。
        S       ゲームを保存する。プログラムも終了します。
                [再開するには、同じキャラクター名で再びプレイします]
                [「データを保存してプレイを続ける」機能はありません]
        t       物を投げるか、弾を撃つ。
        T       防具を脱ぐ。
        ^T      テレポートする（できる場合）。
        v       バージョン番号を表示する。
        V       ゲームの歴史を含む、より詳しいバージョン情報を表示する。
        w       武器を構える。w- は何も持たず素手になる。
        W       防具を着る。
        x       構えた武器と予備の武器を入れ替える。
        X       二刀流を切り替える。
        ^X      自分の能力を表示する。
        #explore  探検モード（発見モードとも言う）に切り替える。このモードでは
                死亡や、再開時のセーブファイル削除を取り消せます。
        z       杖を振る。（number_pad が -1 のときは z でなく y）
        Z       呪文を唱える。（number_pad が -1 のときは Z でなく Y）
        ^Z      ゲームを一時停止する。（number_pad が -1 のときは ^Z でなく ^Y）
                [再開するにはシェルコマンド 'fg' を使います]
        :       ここに何があるかを見る。
        ;       別の場所に何があるかを見る。
        ,       物を拾う。
        @       自動拾いオプションを切り替える。
        ^       以前に見つけた罠の種類を尋ねる。
        )       構えている武器を教える。
        [       着ている防具を教える。
        =       着けている指輪を教える。
        "       着けている護符を教える。
        (       使っている道具を教える。
        *       使っている装備を教える。上の5つをまとめたもの。
        $       所持金を数える。
        +       覚えている呪文を一覧表示する。必要なら並べ替えられる。
        \       判明しているアイテムの種類を表示する。
        `       アイテムの分類ごとに、判明している種類を表示する。
        !       シェルへ抜ける（バージョンと OS が対応している場合）。
                [プレイに戻るには、'exit' でシェルを終了します]
        #       「拡張」コマンドを入力する。"#" で使えるコマンドの一覧は
                "#?" で表示できます。使える拡張コマンドは、ゲームを
                コンパイルしたときのオプション、職業、そのときの姿に近い
                モンスターの種類によって変わります。キーボードに Meta キー
                （ほかのキーと同時に押すと 'meta'（第8、'high'）ビットを
                立てるキー）があれば、コマンドの最初の文字を Meta 付きで
                入力して拡張コマンドを実行できます。Alt キーでも同じ効果が
                ある場合があります。

        "number_pad" オプションが有効なときは、次の英字コマンドも使えます：

        h       '?' と同じくヘルプメニューを表示する。
        j       別の場所へ跳ぶ。
        k       蹴る（普通は扉を）。
        l       床の箱の中身を調べる。
        n       次のコマンドを繰り返す回数を続けて入力する。
        N       モンスター、個別のアイテム、アイテムの種類に名前を付ける。
        u       アイテムや扉に仕掛けられた罠を解除する。

        コマンドの前に数を付けると、その回数だけ繰り返します。"40." や
        "20s" のように入力します。number_pad オプションを設定しているときは、
        "n40." や "n20s" のように数の前に 'n' を入力します。


        一部の情報は、一番下の行か、環境によっては枠の中に表示されます。
        能力値、属性、今いる階、現在の HP（と全回復したときの HP）、
        AC（低いほど良い）、経験レベル、空腹の状態が分かります。設定に
        よっては、呪文のポイント、所持金などの情報も表示されます。

        楽しんでください。Happy Hacking！
