これは nethack のコマンドライン引数の簡潔な説明です。
UNIX（linux や macOS などの派生を含む）向けに書かれており、ほかの
プラットフォームでは正確でない場合があります。

プレイを始めるとき、選んだキャラクター名のセーブファイルがあれば再開し、
なければその名前で新しいゲームを始めます。

nethack
  引数なし。実行時の設定ファイルの OPTIONS=name:character-name の項目の
  キャラクター名を使います。なければプレイヤーのユーザー名を使います。

nethack -u character-name [-X or -D]
  '-u character-name' このゲームのキャラクターの名前を指定します。
       -u は小文字にしてください。character-name との間の空白は省略できます。
  '-X' スコアが記録されない探検モード（発見モードとも言う）でプレイします。
       -X は大文字にしてください。キャラクターは願いの杖を持って始まり、
       死んでも蘇生を選んで続けられます。
  '-D' デバッグモード（ウィザードモードとも言う）で実行します。-D は大文字に
       してください。許可されていなければ -X に切り替わります。許可されて
       いれば、キャラクター名は "wizard" に変わります。

  キャラクター名の後に、職業、種族、性別、属性を付けられます。たとえば
  -u Conan-Bar-Hum-Mal-Neu や -u Tim-Wiz のようにします。各要素は3文字以上で、
  長くても構いません。大文字と小文字は区別しません。次の -p と -r も参照してください。

nethack -p Ppp -r Rrr [-@]
  '-p Ppp' 職業を指定します。-r が使われているため、"profession" の p を
       使います。'Ppp' は Valkyrie の Val のように職業名の3文字以上です。
       -p と違い、Ppp の大文字と小文字は区別しません。
  '-r Rrr' 種族を指定します：Hum[an]、Elf、Orc、Dwa[rf]、Gno[me]。
  '-@' 対話なしで開始します。コマンドラインと実行時の設定ファイルで指定されて
       いない職業、種族、性別、属性は、尋ねずにランダムに選びます。
       @ はバックスラッシュを前に付けて引用する必要がある場合があります。

  職業の古い指定方法も使えます：-A または -Arc[heologist]、
  -B または -Bar[barian]、-C または -Cav[eman] または -Cavew[oman]、
  -H または -Hea[ler]、-K または -Kni[ght]、-M または -Mon[k]、
  -P または -Pri[est] または -Prieste[ss]、-Ran[ger]、-R または -Rog[ue]、
  -S または -Sam[urai]、-T または -Tou[rist]、-V または -Val[kyrie]、
  -W または -Wiz[ard]。1文字の形は大文字に、3文字以上の形は大文字でも小文字でも
  構いません。Ranger には1文字の形がありません。

nethack -DEC[graphics]
nethack -IBM[graphics]
  文字マップで線画文字を使う DEC または IBM の記号セットを選びます。
  インターフェースによって無視されたり、表示能力によって効果がなかったり、
  文字化けしたりすることがあります。-DECgraphics と -IBMgraphics は同時に
  使えません。大文字でも小文字でも構いませんが、3文字以上にしてください。

nethack -wIii
nethack --windowtype:Iii
  'Iii' はインターフェースの指定です：tty、curses、X11、Qt。複数の
  インターフェースに対応してビルドされている場合にのみ役立ちます（ゲームの
  '#version' コマンドで分かります）。実行時の設定ファイルの
  OPTIONS=windowtype:Iii とビルド時の既定値より優先されます。'-w' と
  '--windowtype' は小文字にしてください。インターフェースの指定自体は大文字でも
  小文字でも構いません。'--windowtype Iii' や '-w Iii' の形でも動作します。

  Windows では、nethack.exe はソースからビルドしたときの設定により tty、curses、
  またはその両方に対応します。nethackW.exe は mswin（Win GUI とも言う）と、
  任意で curses に対応します。MS-DOS 版は tty、curses、またはその両方に対応します。

nethack -n
  nethack のディレクトリに 'news' ファイルがあっても表示しません。

nethack --nethackrc:RC-file
  既定の実行時設定ファイル（通常は '~/.nethackrc'）の代わりに RC-file を
  使います。nethack のディレクトリにない場合は、ファイル名にフルパスを含めて
  ください。
nethack --no-nethackrc
  実行時の設定ファイルを使いません。空のファイルのように働く
  --nethackrc:/dev/null と同じです。

nethack -dDir
nethack --directory:Dir
  ビルド時の NETHACKDIR の値を、場所 Dir で置き換えられます。使う場合は、
  ほかのコマンドライン引数より前に置いてください。

上のさまざまなオプションは1つのコマンドラインで組み合わせられます。
読みやすさのために分けて記載しています。

*******

ゲームをプレイせず、何かを実行して終了するオプション：

nethack -s
nethack --scores
  既定のキャラクターのスコアを表示します。追加の引数を指定できます：
nethack -s -v
  ハイスコアファイル（record）に古いバージョンのスコアがあれば、すべての
  バージョンのスコアを表示します。既定では現在のバージョンのスコアだけを
  表示します。'-v' を使う場合は -s や --scores のすぐ後、名前、-p、-r より前に
  置いてください。
nethack -s character-name [character-name2 [character-name3 [...]]]
  1つ以上の特定のキャラクター名のスコアを表示します（nethack の sysconf
  ファイルで PERS_IS_UID=1 が指定されていると効果がない場合があります）。
  キャラクター名の前に '-u' を付けられますが、必須ではありません。特別な
  キャラクター名 "all" を使うと、ほかの条件を満たすすべてのスコアを表示します。
nethack -s -p Ppp -r Rrr
  特定の職業や種族のスコアを表示します。複数指定できます。'-p' と '-r' の両方を
  使うと、両方に一致するものではなく、どちらかに一致するスコアを表示します。
nethack -dDir -s
nethack --directory:Dir -s
  上と同じです。別のディレクトリを指定する場合は最初に置いてください。

nethack --version or --version:copy or --version:dump or --version:show
  '--version' プログラムのバージョン番号と、ソースコードからビルドした日時を
  表示して終了します。
  '--version:copy' バージョン番号を表示し、システムのクリップボードにコピーして
  終了します（macOS と Windows では動作するはずですが、ほかのシステムでは動作
  しない場合があります）。メールや Web の問い合わせフォームに貼り付けられます。
  '--version:dump' いくつかの内部の値を表示して終了します。
  '--version:show' '--version' と同じです。

nethack --showpaths
  さまざまなファイルとディレクトリの想定される場所を一覧表示して終了します。
  プラットフォームによって異なる実行時の設定ファイルの名前と場所も含みます。

nethack --usage
nethack --help
  この説明を表示します。'nethack -?' と 'nethack ?' でも動作しますが、シェルに
  解釈されないよう疑問符を引用する必要がある場合があります。

*******

この説明は、プレイ中にゲームの '?' コマンドのメニューから、またはシェルの
プロンプトで 'nethack --usage | more' を実行して見られます。
