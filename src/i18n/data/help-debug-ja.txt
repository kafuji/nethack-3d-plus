デバッグモード早見表：

^E  ==  近くの隠し扉と罠を探知する
^F  ==  階の地図を表示する。罠と隠し通路は分かるが、隠し扉は分からない
^G  ==  名前か分類を指定してモンスターを生成する
^I  ==  持ち物を識別する
^T  ==  同じ階の中でテレポートする
^V  ==  別の階へテレポートする。'?' で特別な行き先のメニューを表示する
^W  ==  アイテム、罠、一部の地形を願う
^X  ==  状態、能力、特性を表示する（拡張された啓蒙）

#debugfuzzer    == ゲームを自動操作にする。失敗するまで続け、
                   impossible 警告を panic に格上げする
#levelchange    == 主人公の経験レベルを設定する
#lightsources   == 移動する光源を表示する
#migratemons    == 移動中のモンスターを表示する。[Opt] 生成もできる
#panic          == パニックのテスト（注意：現在のゲームが終了します）
#polyself       == 自分を変化させる
#stats          == メモリの統計を表示する
#terrain        == 現在の階を表示する（通常プレイより選択肢が多い）
#timeout        == タイムアウトキューと主人公の時限特性を見る
#vision         == 視界の配列を表示する
#wizborn        == モンスターの誕生、死亡、抹殺、絶滅の統計を表示する
#wizcast        == 任意の呪文を唱える
#wizdispmacros  == [Opt] 内部の表示分類を検査する
#wizfliplevel   == 現在の階を反転する
#wizintrinsic   == 選んだ特性のタイムアウトを設定する
#wizkill        == モンスターをゲームから取り除く
#wizloaddes     == 特別な階の説明の lua スクリプトを読み込んで実行する
#wizloadlua     == lua スクリプトを読み込んで実行する
#wizmakemap     == 現在の階を作り直す
#wizmondiff     == [Opt] モンスターの難易度の不一致を検査する
#wizobjprobs    == [Opt] アイテムが生成される実際の確率を一覧表示する
#wizrumorcheck  == 噂の索引を検査する。ランダムな刻印、墓碑銘、幻覚の
                   モンスターの最初、2番目、最後も表示する
#wizseenv       == マップの各地点の seen ベクトルを表示する
#wizsmell       == モンスターのにおいをかぐ
#wiztelekinesis == モンスターを魔法で押す
#wizwhere       == すべての特別な階の配置を表示する
#wmode          == 壁のモードを表示する

オプション：
debug_hunger    == 主人公の空腹を無効にする
debug_mongen    == モンスターのランダム生成を無効にする
debug_overwrite_stairs
                == 階段をほかの地形に置き換えられるようにする
monpolycontrol  == モンスターが姿を変えるたびに新しい姿を尋ねる
sanity_check    == 各ターンの前にモンスター、アイテム、マップを検査する
wizweight       == アイテムの説明に重さを加える

[Opt] = ビルド時の設定によって使える場合がある
