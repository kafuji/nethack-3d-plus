# Game text translation data

`data/jnethack.generated.json` is generated by
`scripts/plus/extract-jnethack-texts.mjs` from:

- JNetHack (https://github.com/jnethack/jnethack-alpha), the Japanese
  localization of NetHack by the JNetHack project, and
- NetHack (https://github.com/NetHack/NetHack), used to pair JNetHack's
  translated names with the original English names.

Both are distributed under the NetHack General Public License; the
Japanese text in the generated data remains under that license. Regenerate
with:

```bash
node scripts/plus/extract-jnethack-texts.mjs <jnethack-checkout> <nethack-checkout>
```
