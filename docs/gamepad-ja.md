# ゲームパッド操作

Xbox 配列のゲームパッドを接続し、画面に表示される確認でコントローラーを有効にします。接続しても検出されない場合は、ボタンを一度押してください。「オプション」→「操作」→「コントローラー対応を有効化」からも有効・無効とボタン割り当てを変更できます。有効設定は次回起動時にも復元されます。

既定の割り当ては以下の通りです。画面や状況によって操作が変わります。

| 操作 | ボタン |
| --- | --- |
| 移動 | 俯瞰視点では方向パッドを押して離す、または左スティックで方向を選んで A / RT で決定。一人称視点では方向パッドまたは左スティック |
| カメラ / 視点 | 右スティック |
| 決定 | A / RT |
| キャンセル / 対象の操作 | B |
| 探索 | X |
| インベントリ | Y |
| アクションメニュー | LB |
| 走行 | LT を押しながら移動 |
| ズーム・カメラ回転 | RB を押しながら左スティック上下・右スティック |
| 大きなミニマップ | 右スティック押し込み |
| ポーズ | Menu / Start |
| キャラクター情報 | View / Back |

ダイアログでは方向パッドで項目を選び、A で決定、B で戻ります。左スティックで仮想カーソル、右スティックでスクロールもできます。文字入力が必要な場面ではキーボードを使用してください。
